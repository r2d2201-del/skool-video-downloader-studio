# Chrome Web Store Listing & Permissions Justifications

## Metadata
- **Name**: Skool Video Downloader
- **Version**: 2.0.0
- **Category**: Productivity / Developer Tools
- **Short Description**: Download videos from Skool classrooms, community posts, and about pages (Loom, Wistia, Vimeo, YouTube & HLS streams).
- **Primary Language**: Spanish / English

## Permissions Justification

### activeTab
Used to interact with the currently active Skool lesson tab when the user opens the extension popup to detect video elements on the page.

### scripting
Required to execute content inspection scripts on Skool lesson pages to extract lesson metadata (`__NEXT_DATA__` JSON) and detect embedded player elements (Loom, Wistia, Vimeo, YouTube).

### downloads
Required to trigger direct file downloads of exported URL lists, CSV syllabus sheets, and batch downloader scripts (`.sh`, `.bat`) generated by the extension.

### storage
Used to temporarily store detected HLS `.m3u8` network streams per browser tab during the active session (`chrome.storage.session`).

### webRequest
Required to sniff background network stream requests matching Fastly and Cloudflare CDN manifests (`*.fastly.video.skool.com` and `stream.video.skool.com`) containing signed video tokens.

### clipboardRead
Used to allow quick copying and pasting of lesson and video URLs in the extension popup.

### contextMenus
Used to add right-click context menu options on Skool pages for one-click video extraction.

### notifications
Used to notify the user when video streams are successfully captured or when bulk exports are generated.

### tabs
Required to query the active tab URL and title to accurately label video downloads according to their lesson titles.

## Host Permissions
- `*://*.skool.com/*`: To detect and inspect lesson pages, community posts, and classroom syllabi.
- `*://*.fastly.video.skool.com/*`: To detect and capture Fastly CDN HLS playlist manifests with signed query tokens.
- `*://stream.video.skool.com/*`: To capture Cloudflare CDN HLS stream manifests with playback tokens.
- `*://*.loom.com/*`: To detect embedded Loom video shares.
- `*://*.wistia.com/*`: To detect embedded Wistia video players.
- `*://*.vimeo.com/*`: To detect embedded Vimeo iframe players.
